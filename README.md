# Лендинг закрытого канала — Исмаил Мустабиров

Одностраничный лендинг закрытого Telegram-канала эксперта (продюсер, запуски).
Демо-версия для показа: анимированная сфера, цена 99 ₽ со спец-таймером 15 минут,
подкаст голосом эксперта, блок «Кто я» с фото.

## Файлы
- `index.html` — вся страница, самодостаточная (шрифты Oswald/Inter и анимация сферы вшиты внутрь).
- `ismail.jpg` — фото эксперта (блок «Кто я»).
- `ismail-podcast.mp3` — подкаст (аудио-плеер на странице).

## Как посмотреть
Открыть `index.html` в браузере (или отдать через любой статический хостинг / GitHub Pages).

## Статус
Демо. Оплата — заглушка (жёлтая плашка «демо»). Боевая версия с реальной оплатой
(CloudPayments) и автовыдачей доступа в закрытый канал — после получения ключей кассы
эксперта и его домена.
